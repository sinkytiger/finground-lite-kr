# 근거 논문 분석

이 프로젝트는 두 논문의 아이디어를 한국 DART 공시에 맞게 다시 구현한 것입니다. 두 논문 모두 영어 SEC 공시만 다룹니다.

## VeriFin (arXiv 2608.10213, 2026-08-10)

Hall, Shome, Eiers (Stevens Institute of Technology). *A Neurosymbolic Framework for Verifying LLM-Generated Financial Claims.*

### 문제 설정

LLM이 공시에서 뽑은 숫자 답변은 그럴듯하지만 기간·단위·계정·공식을 틀리기 쉽습니다. 저자들은 질문을 "답을 맞힐 수 있는가"에서 **"이 숫자를 업무에 받아들여도 되는가"(acceptance control)** 로 바꿉니다. 틀린 숫자를 받아들이는 것(false accept)을 가장 큰 위험으로 보고, 근거가 부족하면 판정을 **보류**(Abstain)하는 것을 명시적인 통제 결정으로 둡니다.

### 방법

1. **검증 계획(Verification Planner)**: LLM이 질문과 근거를 읽고 지표, 공식, 피연산자 역할, 단위, 기간을 적습니다. 후보 답변은 이 계획에 영향을 주지 못합니다.
2. **출처 검증(Provenance Verifier)**: 각 피연산자를 XBRL 공시 사실(개념·기간·단위·값)에 묶습니다. 값은 **공시에서만** 가져오고, 모델이 뽑은 숫자는 버립니다(value-blind binding). 공식은 질문 문구, 공시의 calculation linkbase, 지표 정의집, 공시 본문 정의 순으로만 허가합니다. 하나라도 확정하지 못하면 보류합니다.
3. **주장 검증(Claim Verifier)**: 묶인 값과 공식, 후보값을 산술 제약으로 만들어 Z3로 판정합니다. 허용 오차 τ는 공시가 표기한 마지막 자릿수의 절반입니다. 모순이면 UNSAT core가 충돌하는 사실·공식·주장을 가리킵니다.

### 결과

- 벤치마크 XBRLFiling: 미국 28개사 10-K의 calculation linkbase에서 소계 15종을 골라, 공시가 선언한 합산 관계에서 거꾸로 600문항을 만들었습니다. 정답은 공시값 자체입니다.
- 같은 후보 답변(Claude Haiku 4.5 생성)을 모든 검증 방법에 주었을 때, VeriFin은 틀린 주장 92개를 **하나도 수용하지 않았습니다**. 기준선은 6~92개를 수용했습니다. 정답 공식과 피연산자를 함께 준 LLM 판정자(Judge+Formula)도 75개를 수용했습니다.
- 답변 생성 모델 6종 모두에서 false accept 0건. 대가로 맞는 주장도 37~73개를 기각했습니다(보수적). FinanceBench에서는 커버리지가 80.6%로 떨어집니다.
- 검증기 진단을 주고 다시 고치게 하면 복구율이 6.5%→46.3%(Qwen3-30B), 최대 69.9%(pass@3)로 올랐습니다. 일반 재시도는 거의 효과가 없었습니다.
- 비용: 문항당 LLM 호출 4~6회, 12k~17k 토큰, 3~9초. Z3는 중앙값 5ms.

### 한계

- 영어 10-K만. 회계연도 체계와 보고서 열 구조가 다른 한국 공시에는 그대로 쓸 수 없습니다.
- 공개 저장소(`verifiedfinance/anon`)는 익명 심사용 스냅샷이며 소프트웨어 라이선스가 정해지지 않았습니다. 이 프로젝트는 그 코드를 쓰지 않고 새로 구현했습니다.

## FinGround (arXiv 2604.23588, 2026-04-26, ACL 2026 Industry Track)

Guo, Wu, Yiu (홍콩대·Stellaris AI). *Detecting and Grounding Financial Hallucinations via Atomic Claim Verification.*

### 방법

1. 금융 특화 하이브리드 검색(본문 + 표).
2. 답변을 원자 주장으로 쪼개고 6유형(수치, 시점, 개체 속성, 비교, 규제, 계산)으로 분류해 유형별로 검증합니다. 계산 주장은 공식 템플릿 47개로 재구성해 ±0.5%로 다시 계산합니다.
3. 틀린 구간만 고쳐 쓰고 문단·표 셀 단위 인용을 붙입니다.
4. GPT-4o 판정을 8B 모델로 증류(F1 91.4%, 지연 18배 단축).

### 결과와 교훈

- 환각률 평균 4.1%, GPT-4o+CoT 대비 78% 감소. 모든 시스템에 같은 검색 결과를 준 비교(retrieval-equalized)에서도 68~76% 감소.
- 계산 주장의 환각률이 가장 높고(28.4%), 일반 검증기는 계산 오류의 57%만 잡았습니다.
- 오탐의 52%는 완곡 표현("approximately", "may")에서, 31%는 정정 수치에서 나왔습니다. 정답과 ±5% 안의 근접 오류는 71%만 잡았습니다.
- 분석가 파일럿에서 가장 유용했던 것은 "원문은 4.2B인데 답변은 4.8B" 같은 구체적 충돌 설명과 표 셀 단위 인용이었습니다.

### 한계

- 영어 SEC만. 평가가 GPT 계열에 의존. 미세조정 모델 4개가 필요.
- 논문에 적힌 공개 저장소(`bettyguo/FinGround`)는 2026-10-09 기준 존재하지 않았습니다.

## 이 프로젝트가 가져온 것과 바꾼 것

| 논문 | 가져온 것 | 바꾼 것 |
|---|---|---|
| VeriFin | 주장과 독립적인 사실·공식 확정, 3-판정(보류 포함), 표기 정밀도 절반 오차, TA/FA/TR/FR/Abs 지표, 진단을 이용한 수정·재검증, 공시값에서 거꾸로 만드는 벤치마크 | XBRL linkbase 대신 DART OpenAPI의 구조화된 재무제표 조회. Z3 대신 십진 산술(v1 검사는 공식 하나와 허용 오차 비교라 결정이 같음). UNSAT core 대신 한국 공시 함정 해석 대조 |
| FinGround | 주장 유형 분류, 계산 주장의 공식 재구성, 출처 인용, 구체적 충돌 설명 | 학습 모델 없이 규칙 검증. 완곡 표현은 한 단위까지 허용하고 표시 |

한국 공시에서만 생기는 요소를 더했습니다: 연결/별도 구분, 분기·반기보고서의 3개월 열과 누적 열, 지배주주 순이익과 당기순이익의 구분, 억·조 단위, 절사 표기 관행, 기사 날짜 기준 보고서 제출 여부.
